冰箱小精灵 当前已验证接线图

主控开发板：
- ESP32-S3-DevKitC-1 N8R8

一、光照传感器（模拟光敏模块）

模块引脚 -> ESP32-S3 引脚
- VCC -> 3V3
- GND -> GND
- IO/AO -> GPIO1

说明：
- 当前按模拟量读取使用。
- GPIO1 对应 ADC1_CH0。
- Web 面板显示的 0-1023 数值由 12-bit ADC 原始值换算得到。
- 光照模块必须使用 3.3V 供电，避免 AO/IO 输出超过 ESP32-S3 ADC 允许范围。

二、INMP441 I2S 麦克风

模块引脚 -> ESP32-S3 引脚
- VDD -> 3V3
- GND -> GND
- SCK -> GPIO40
- WS  -> GPIO41
- SD  -> GPIO42
- L/R -> GND

说明：
- L/R 接 GND 表示当前使用左声道。
- 如果后续出现数据异常、转写异常或怀疑声道选择不对，可临时改为 L/R -> 3V3 测试右声道。
- 当前固件录音参数为 16 kHz / 单声道 / 16-bit PCM。

三、接线注意事项

- 所有模块必须与 ESP32-S3 共地。
- 传感器和麦克风都使用 3.3V 供电，不要接 5V 到 ESP32 GPIO。
- I2S 线尽量短，杜邦线接触要稳，避免 timeout 和杂音。
- 接线修改后先观察是否有异常发热、反复重启、brownout，再进行功能测试。
